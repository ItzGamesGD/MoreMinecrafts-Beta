# Custom Mob Production Texture Manifest

Status: **40 texture candidates are present; production approval and in-game visual review remain pending under the current content authority.**

Each base texture is routed through its existing vanilla-family renderer. Models, skeletons, animations, gameplay, and VFX are unchanged. The official 26.3 client JAR was `e877b6a07acd633fb3bb475002175cec036e7b87`; the `Vanilla template` values below are its exact internal resource paths.

The prior production manifest records the creation method for all 40 as localized pixel-art atlas edits using mob-specific art direction, nearest-neighbor resampling to official template dimensions, palette quantization, and restoration of official per-pixel alpha masks. This audit independently verified the SHA-1 of the cited client JAR, the dimensions and per-pixel alpha masks of all 78 base and state/overlay PNGs against their corresponding vanilla templates, and that all 78 PNGs decode. Pixel-level UV region correctness and in-game appearance have not been independently verified here.

The prior manifest and PR description report in-game screenshots and a passing visual review, but the referenced `/workspace/MoreMinecrafts-40-Mob-Texture-Review.zip` is not available in this checkout, and the current Oct 7 content-authority record still says production artwork and in-game review are pending. The filenames below are therefore reported captures, not evidence verified in this audit. Visual QA remains **LIVE VALIDATION PENDING**.

**Provenance and redistribution:** the listed source templates come from the official Minecraft 26.3 client JAR (SHA-1 `e877b6a07acd633fb3bb475002175cec036e7b87`). The 78 PNGs are derived from those templates. The repository does not record an applicable license assessment, redistribution grant, or release status for these derivatives. This audit does not infer permission from the source hash or creation method; that status remains unconfirmed.

## Texture state companions

The main roster above names the one dedicated base texture per mob. Every companion retains its official template size and alpha mask. The implementation routes these through existing vanilla layers and preserves their normal state predicates.
