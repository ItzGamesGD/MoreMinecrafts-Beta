# Custom Mob Production Texture Manifest

Status: **40 production texture candidates completed and visually reviewed in Minecraft 26.3; ready for repository review.**

Each base texture is routed through its existing vanilla-family renderer. Models, skeletons, animations, gameplay, and VFX are unchanged. The official 26.3 client JAR was `e877b6a07acd633fb3bb475002175cec036e7b87`; the `Vanilla template` values below are its exact internal resource paths.

Creation method for all 40: localized pixel-art atlas edits using the mob-specific art direction, nearest-neighbor resampling to the exact official template dimensions, palette quantization, and restoration of the official per-pixel alpha mask. UV regions and alpha semantics are preserved. State/overlay companion assets use the exact official baby, outer-layer, emissive, eye, and power-overlay masks as applicable; 78 PNG resources are routed in total.

Visual QA: each mob was seen in actual Minecraft front and opposite-side family captures. Technical checks covered UV placement, visible face/limbs/sides, alpha, renderer family, overlays, and equipment. No obvious technical texture defect remained. Specific Mob → screenshot mapping is listed per row. Detail screenshots cover the compact bug model and complex spider, drowned, bee, phantom, and creeper paths.

## Texture state companions

The main roster above names the one dedicated base texture per mob. Renderer state is preserved through additional vanilla-compatible assets where necessary: Zombie and Piglin baby textures; Drowned baby and outer layers; Mountain Skeleton (Stray) overlay; Spider eyes; Bee/Wolf baby and state variants; Phantom eyes; and Cave Creeper power armor. Every companion retains its official template size and alpha mask. The implementation routes these through existing vanilla layers and preserves their normal state predicates.

## Review notes

- 40/40 roster entries have a dedicated base PNG and renderer route.
- 78/78 PNG resources decode and match their exact official template dimensions and alpha masks.
- Front and opposite-side screenshots are from the Minecraft client, not external renderers.
- Screenshots use a controlled flat test floor, night vision, NoAI test NBT, and entity labels. No test behavior is stored in production code.
- Visual review passed with no obvious UV seam, reversed face/body region, missing overlay, unintended transparency, or vanilla fallback. The production art remains a candidate for human approval.
