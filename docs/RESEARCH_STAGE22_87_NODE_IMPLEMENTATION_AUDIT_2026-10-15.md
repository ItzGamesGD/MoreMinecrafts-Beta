# Stage 22: Full 87-Node Research Implementation Audit (2026-10-15)

## Scope and method

Audit covers the baseline 70 V3 + 17 V4 research nodes, excluding the five Stage 22 roots added by this execution. Intended effects come from the current approved research effect authority in `docs/RESEARCH_KNOWLEDGE_TIER_DESIGN_2026-10-08.md` (Research Effects V2, the later accepted ecology/world/alchemy rules, and V4 execution authority) and the Stage 22 topology authority. Registration, purchase eligibility, runtime effect handling, research gating, and effect-level verification were checked separately.

Common implementation evidence: V3 IDs/prices in `src/main/resources/data/moreminecrafts/research/research_v3.json`; V4 IDs/prices in `src/main/java/dev/itzgamesgd/moreminecrafts/progression/ResearchCatalog.java`; purchase validation/transaction in `ResearchPurchaseRules.java` and `ResearchPurchaseService.java`; screen data and lock state in `ProgressionScreenData.java` / `ProgressionTreeCanvas.java`; effect descriptors in `ResearchRewards.java`. A descriptor or node layout is not counted as a gameplay handler.

Common test evidence: `ResearchV3LedgerTest` and `ResearchV3CatalogTest` validate catalog/cost data; `ResearchPurchasePrerequisiteTest` exercises generic purchase rules. These do not prove any specific research gameplay effect. The focused runtime effect evidence listed below was searched by research ID and handler path; no V3 ID-to-effect handler was present.

## Stage 22 root-passive implementation status (outside the 87-node roster)

Source handlers are present for all seven roots: ore XP orbs, furnace-result smelting XP orbs, nearby natural CropBlock growth rolls, hostile-Monster XP orbs, hostile damage, grounded movement speed, and beneficial timed effects on consumed drinkable potions. Mapped Minecraft 26.3 source confirmed the LivingEntity death XP hook, ExperienceOrb award hook, CropBlock random tick, FurnaceResultSlot take hook, and potion consume-effect hook. XP fractional remainders live in the persistent per-player progression attachment. Each hook queries the paid research level at the event, so reconnects do not reapply or stack a transient reward. Focused JUnit tests cover shared fraction handling, repeat events, crop probability, duration rounding, base scaling, serialization, player-private state, and all seven root reward gates. Java 25 CI passed the JUnit task, all 96 GameTests, main server smoke, client smoke, and two-process persistence run. The K5 chunk provenance GameTest timeout was raised to accommodate its five bounded asynchronous chunk phases (240 ticks each). Root gameplay handlers initialize successfully, but there are no dedicated effect-by-effect gameplay tests; Alchemy currently supports consumed drinkable potions, while splash/lingering potions are outside this hook. The full runtime GameTest suite passed; it does not prove the root effects individually. Ecology classification for hostile custom mobs remains subject to the section 7 roster/tag audit.
