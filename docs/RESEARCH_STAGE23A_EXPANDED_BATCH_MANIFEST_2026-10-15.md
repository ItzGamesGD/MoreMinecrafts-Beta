## Selection

The six selected IDs are `.06`, `.07`, `.11`, `.44`, `.45`, and `.47`. The first three reuse PR #96's permanent furnace attribution and saved fractional state. The latter three use the existing player damage hook and explicit entity tags. A full scan of the 40 custom mob registry entries found three Drowned variants to include for `.45`, and no custom Hoglin or boss variants. The free knowledge +5% for these three families is applied once per target; paid and free family percentages add before the existing general combat bonuses compose. Portable furnace session processing remains outside this batch's permanent-furnace effects because the existing item-backed session does not preserve its cooking inventory across close/reopen.

Skipped high-priority candidates: `.46` is category C because rare species are still tentative and the exact taxonomy is pending. `.26`, `.59`, and `.66` are category D because the fish trap or brewing stand lacks an attributed research owner. `.49` is category D for the missing approved powered boat; an ordinary boat subset could be a later compatible slice. Other rows are deferred by batch size or higher integration cost, as shown below; they are not described as blocked research nodes in the canonical audit. PR #95 Precision Crafting `.08` and its crafting mixins/tags were not edited.

## Validation and remaining checks

Java 25 local `./gradlew clean test build compileGametestJava runGameTest` passed with **109 required GameTests** after registering the new and previously unregistered furnace tests. The existing two-process restart fixture passed its separate write and read runs, including furnace block-entity state and offline player attachment resolution. The local dedicated server reached `Done (4.370s)` and stayed running until the 150-second smoke timeout without fatal startup markers. Minecraft 26.3 mapped class signatures for `serverTick`, `getBurnDuration`, `canBurn`, and `burn` were checked against the generated mapped jar; the GameTests exercised the transformed server class. `git diff --check` passed. The local environment has no Xvfb, so the client smoke and full mapped-source workflow are CI checks on the Draft PR.

Live checks remain for multiplayer owner handoff; GUI, hopper, and automation composition; fuel container types; long-running fuel and speed percentages; full-output pause/restart; every mineral tag extension and modded recipe; Auto Smelt independence; Hoglin, Guardian, custom Drowned, Ender Dragon, and Wither damage; and client/server display synchronization. These six nodes stay PARTIAL until live evidence exists.

Design decisions still needed for later work are a lifecycle-compatible way to apply furnace research inside portable sessions without changing close/drop behavior; a final rare-mob taxonomy for `.46`; research attribution for fish traps and brewing stands; and powered-boat implementation for the remaining portion of `.49`. None was inferred in this batch.

Compatibility limits: Minecraft 26.3 persists the furnace burn duration as an integer, so this runtime leaves a fuel unchanged only if applying `.06` would exceed `Integer.MAX_VALUE`. A one-tick cooking recipe cannot complete more than once in a server tick; `.11` caps whole-tick credit there. A tagged mineral recipe whose possible bonus cannot fit its output slot pauses without consuming input or fuel; it needs an approved output path before it can resume.
