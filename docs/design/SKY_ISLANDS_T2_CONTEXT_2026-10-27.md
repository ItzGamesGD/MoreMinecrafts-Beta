기록일: 2026-10-27  
상태: **설계 진행 중. 구현 완료 문서가 아님.**  
**모든 설계 결정이 완료되기 전에는 Claude/Codex 최종 구현 지시문을 작성하지 않는다.**

## 1. T2 무기와 제작 재료

- 기본 철/금/다이아/네더라이트 검 재질이 T2 무기의 티어를 결정하지 않는다. 희귀 재료와 탐험으로 제작 난이도를 조절한다. 무기는 반복 제작 가능하고 고유 텍스처/모델을 갖는다.
- **불꽃검**: 금검 ×1, 불타는 심장 ×1, 네더라이트 주괴 ×1, 아다만티움 주괴 ×1.
- **흐르는 물의 검**: 다이아몬드 검 ×1, 프리즈머린 조각 ×5, 바다의 심장 ×2, 해류의 심장 ×1. 사용자는 바다의 심장을 상대적으로 쉽게 구할 수 있다고 판단.
- **바람을 가르는 검**: 철검 ×1, 태풍의 눈 ×1, 브리즈 막대 ×4, 미스릴 주괴 ×1, **천공의 깃털 ×2**. 실제 미스릴 아이템 ID는 구현 전 검증; `mythril` 가능성을 확인하고 `mythril_ingot`으로 임의 단정 금지.
- **번개의 검**: 천둥의 심장 ×1 확정, 나머지 재료 미정.
- 위 네 검의 실제 3×3 제작 배치는 미정.
- **대지의 철퇴** 확정 3×3:
```text
다이아몬드 블록 | 무거운 핵       | 다이아몬드 블록
빈칸             | 고대의 심장     | 빈칸
빈칸             | 네더라이트 주괴 | 빈칸
```
  출력 1개. 피라미드 PR #181 원안 및 PR #189/#182 관련 F-2 결정으로 중앙 고대의 심장. **조합 설계 확정이지 코드 구현 확인 아님**.
- T3와 T4는 독립 체계(T4가 T3 진화형 아님). 바람 활과 마법 지팡이 제작법은 보류.

### 원소 핵심 재료 획득
- 불타는 심장: 보루 잔해 보물 상자 약 4% (잠정 설계).
- 해류의 심장: 해저 유적의 엘더 가디언을 모두 처치한 경우 해당 구조물당 1회 획득 설계.
- 태풍의 눈·천둥의 심장: 시련 5단계 보상과 연계. 일반/불길한 금고의 실제 구현은 검증 필요.
- 전달된 T2-ACQ-AUDIT-2026-10-26-01 / PR #182 감사: 불타는 심장·해류의 심장 관련 코드는 있으나 **LIVE UNVERIFIED**. main의 Ocean Monument 구조물 ID 오류 및 미병합 브랜치 수정 보고가 있었음. 이번 문서 작성 시 재감사하지 않음.

## 2. 천공의 깃털 획득과 희귀성

- 바람을 가르는 검에 깃털 2개 필요.
- 획득처: (1) 아래 신규 비행 몬스터 3종, (2) **향후 신규 오버월드 공중 구조물**의 공통 전리품 풀.
- 기존 바닐라 구조물의 전리품은 변경하지 않음.
- 공중 구조물의 **보상 상자당 정확히 1회 추첨**, **5% 확률로 깃털 정확히 1개**. 실패하면 0개. 한 상자에서 2개 이상 없음. 부유 유적과 천공 신전에 적용. 일반 하늘섬은 상자 필수 아님.
- 새 공중 구조물들이 공통 보상 풀을 참조하는 구조는 **구현 요구사항**, 구현된 상태가 아님.
- 몬스터 스폰과 깃털 드롭 모두 낮게 유지. 다른 하늘 몬스터를 늘려도 깃털이 흔해져서는 안 됨. **약탈(Looting)은 드롭 확률과 수량 모두에 영향 없음.**

## 3. 이미 확정된 신규 비행 몬스터 3종

세 종류는 **독립 신규 엔티티**, 초기에는 바닐라 모델/텍스처를 재사용하고 추후 리소스 교체 가능. 명칭은 잠정.

### 하늘의 정령 / Sky Spirit
- 알레이 모델 기반. '일반적인 종류'이지만 실제 자연 스폰은 **낮음**.
- 중립형: 선공하지 않고, 공격받으면 바람 탄환으로 반격하며 공격자를 추적. 시야가 끊기거나 충분히 멀어지면 추적 종료.
- 낮에 1~2마리씩 스폰. 기준 바이옴: **Meadow, Snowy Slopes, Jagged Peaks**.
- 깃털: **3% 확률로 1개**. 약탈 미적용.
- 알레이 기존 비행 모션 최대한 활용. 별도 전용 전투 애니메이션은 만들지 않되 투사체 발사 방향/위치는 자연스럽게.

### 폭풍의 사냥꾼 / Storm Hunter
- 팬텀 모델 기반. 희귀 정예·선공형.
- 패턴: **공중 선회 → 바람 탄환 발사 → 급강하 근접 공격 → 재상승**.
- 밤에 1마리씩 스폰. 기준 바이옴: **Jagged Peaks, Stony Peaks, Badlands**.
- 깃털: **6% 확률로 드롭 성공**; 성공 시 **1개 80%, 2개 20%**. 전체 확률 0개 94%, 1개 4.8%, 2개 1.2%. 약탈 미적용.
- 팬텀 기존 비행/급강하 모션 활용. 별도 전용 애니메이션 없음.

### 천공의 비룡 / Sky Wyvern
- **축소된 엔더 드래곤 모델** 기반 독립 신규 엔티티. 엔더 드래곤 보스 AI, 체력바, 페이즈 사용 안 함.
- **극희귀 정예**, 선공형. 다이아몬드급 장비로 패턴을 숙지하면 상대 가능한 난이도.
- 낮·밤 모두 1마리씩 스폰. 기준 바이옴: **Stony Peaks, Badlands, Eroded Badlands**.
- **최대 체력 60 HP**.
- **일반 난이도 / 방어력 적용 전 피해량**:
  - 바람 브레스 **6 HP**: 전방 광역 **순수 피해**, 넉백이나 공중 띄우기 없음.
  - 급강하 돌진 **8 HP**: 빠르게 접근해 근접 타격.
  - 날개 밀쳐내기 **3 HP + 넉백**: 플레이어가 근접했을 때 쓰는 방어형 공격. 돌진 직후 필수 연계 아님.
- 날개 사거리, 넉백 세기, 쿨다운 등은 미정.
- 깃털 **10% 확률로 정확히 2개**, 실패 90%. 약탈 미적용.
- 일반 전리품 **추가 확정**: 팬텀 막, 뼈 같은 기존 아이템을 소량. 정확한 아이템 목록/확률/수량 미정. 신규 전용 부산물 아이템은 만들지 않음.
- **비룡에만 전용 애니메이션**: 날갯짓·선회, 브레스 준비(머리 조준)·발사, 돌진 자세, 날개 휘두르기, 피격 반응. 공격 판정과 모션 동기화 필수. 엔더 드래곤 모델 재사용 범위를 기술 검증하고 필요 시 전용 모델 계층/컨트롤러 도입 가능. 전투 수치 임의 변경 금지.

### 바이옴 목록에 대한 제한적 위임
위 바이옴은 승인된 기준 목록. 최종 구현 에이전트는 실제 Minecraft/Fabric 바이옴 ID·태그·변종·스폰 메커니즘을 근거로 **바이옴 목록만** 보정/추가 가능. **고산 + 메사/악지(Badlands/Eroded Badlands) 테마**, 몬스터별 바이옴 차별화 유지. 이 위임은 드롭률, 시간대, 역할, 제작 재료 등을 수정할 권한이 아님.

## 4. 하늘섬과 공중 구조물

### 지형 및 구조물
- 오버월드에 자연 생성 **하늘섬** 추가.
- **부유 유적**: 작은 폐허·보물 중심의 소형 탐험 구조물.
- **천공 신전**: 몬스터·함정·보물방이 있는 중형 구조물.
- **모든 유적/신전은 하늘섬 위에 생성**. 섬 없이 독립 부유하는 유적/신전 없음. 건축물 없는 일반 하늘섬도 존재.
- 섬 크기는 일반 섬/유적/신전의 목적과 지형에 맞춰 에이전트가 자율 결정·검증. 일률적인 지름 강제 안 함. 과도한 지형 압도는 피함.

### 생성 지역, 고도, 군집
- **산악·고산지대에서 상대적으로 생성 확률이 높지만**, 산마다 무조건 많이/항상 생성되게 하지 않음.
- 평원·숲·사막·악지 등 **다른 오버월드 바이옴에서도 낮은 확률로 생성**.
- 고도 **혼합형**: 산봉우리 근처부터 더 높은 상공까지 다양하며, 섬의 용도/난이도 반영.
- **자연 군집형**: 대부분 독립 섬, 일부는 가까운 섬 여러 개가 군집. 기본적으로 자동 생성 다리/연결로 없음. 섬끼리 겹치거나 규칙적 배열 지양.
- 생성 가중치, 군집 크기, 간격 등 정량 수치는 미정.

### 주변 바이옴 반영
- 설산: 눈·얼음·돌. 평원: 잔디·꽃·드문 나무. 숲: 나무·풀. 악지/메사: 테라코타·붉은 모래. 사막: 모래·사암.
- 일반 섬 및 유적/신전이 놓인 섬의 자연 지형·식생에 적용. 건축물 고유 디자인까지 주변 바이옴에 종속시키지는 않음.

## 5. 하늘섬 몬스터 생태계 — 2026-10-27 최신 확정

### 핵심 철학
- **하늘섬은 오버월드의 자연스러운 연장선**이다. 독립된 판타지 차원이나 전투 전용 콘텐츠가 아니다.
- 몬스터는 각자 특별한 기믹을 제공하기보다 **그 환경에 자연스럽게 존재하는 생물**이어야 한다.
- 복잡한 신규 AI와 전투 패턴을 일반 몬스터에 억지로 부여하지 않는다. 능력치 차이는 제한적으로 사용.
- **평화로운 몹은 바닐라 그대로** 사용하며 새로운 우호적 동물 변종을 만들지 않는다.
- 숫자를 채우기 위한 신규 몬스터 할당량은 **폐지**. 과거 '신규 5~7종', '비행형 3+지상형 3' 목표는 더 이상 강제하지 않는다.

### 지역별 자연 스폰
- **일반 지역 하늘섬:** 주변 바이옴과 바닐라 스폰 규칙(밤·밝기 등)에 따른 일반 몬스터 중심, 변종과 하늘 몬스터는 드물게 등장.
- **고산 상공 하늘섬:** 산 정상보다 높은 하늘섬. 특수 하늘 몬스터와 변종 비중이 상대적으로 높고 일반 지상 몬스터는 제한. 별개 차원의 생태계로 만들지는 않는다.
- 절대 Y 좌표만이 아니라 **주변 지형의 높이, 섬의 상대 고도, 바이옴**을 함께 고려.
- 팬텀은 바닐라 불면증 스폰 조건을 유지하며 하늘섬 전용 추가 스폰으로 취급하지 않음.
- 모든 변종은 **일반 하늘섬에도 드물게**, 고산 상공 하늘섬에서는 상대적으로 자주 등장. 전체 적대 몬스터 밀도를 무분별하게 높이지 않음.

### 채택된 바닐라 적대 몬스터 변종 5종
다섯 원형 종(좀비·스켈레톤·크리퍼·엔더맨·슬라임)과 **5종 모두 채택**은 확정. 아래 이름·세부 외형은 잠정 제안이며 변경 가능.
1. **풍화된 좀비** — 좀비 기반, 낡은 외형, 일부 가죽/사슬 장비, 기본 근접 AI.
2. **천공 궁수** — 스켈레톤 기반, 망토, 일반 활 공격, 화살 피해 소폭 증가.
3. **암석 크리퍼** — 크리퍼 기반, 돌/이끼 외형, 폭발은 바닐라 방식, 체력 소폭 증가.
4. **창백한 엔더맨** — 엔더맨 기반, 창백한 외형, 기본 순간이동·적대 규칙 유지.
5. **푸른 슬라임** — 슬라임 기반, 푸른 반투명 외형, 기본 점프·분열 유지.
- 새로운 복잡한 능력은 추가하지 않으며, 변종의 구체 수치·드롭은 후속 검토.

### 확정 신규 몬스터 4종
1. **하늘의 정령** — 세부 스폰·전투·깃털 확률은 §3 참조.
2. **폭풍의 사냥꾼** — 세부 스폰·전투·깃털 확률은 §3 참조.
3. **천공의 비룡** — 세부 스폰·전투·깃털 확률은 §3 참조.
4. **부유 해파리** — 반투명 몸체와 촉수, 공중에서 느리게 부유. 중립형으로 먼저 공격하지 않고 공격받으면 접촉 반격. 하늘섬에서 **드물게** 자연 발견, 보스/특별 보상용이 아님. **천공의 깃털을 드롭하지 않음**. 세부 스폰 조건과 일반 드롭은 미정.

### 제외 및 유보
- **신규 지상 몬스터 추가 안 함**: 바닐라 몹과 변종으로 충분.
- 다른 신규 비행 몬스터 2종도 **억지로 채우지 않음**. 부유 해파리 이외 제안된 까마귀·나방·가오리·박쥐·딱정벌레·와이번 새끼·비행 해골·포식충·망령 등은 모두 기각.
- 최종 구성: **신규 엔티티 4종 + 바닐라 적대 변종 5종 = 추가 9종**. 기존 바닐라 몹은 별도.

## 6. 미정 사항 / 후속 설계

## 9. 천공의 깃털 사용처 및 비행 포션 — 추가 확정

## 13. T2 원소 무기 공통 광물 — 이더리움 채택 (2026-10-27)

### 18.4 원소 코어 획득 경로 — 과거 경로의 명시적 대체

| 코어 | 최신 OWNER 확정 | 이전 경로 판정 |
|---|---|---|
| 불타는 심장 | 신규 불 보스 처치 드롭 **50% ×1** | 보루 잔해(Bastion) 보물 상자 **4% SUPERSEDED** |
| 해류의 심장 | 신규 바다 보스 처치 드롭 **50% ×1** | 바다 신전 엘더 가디언 전멸 1회 보상 **SUPERSEDED** |
| 태풍의 눈 | **일반 시련 금고 5% ×1** | 기존 일반 금고 2% **SUPERSEDED** |
| 천둥의 심장 | **불길한 시련 금고 5% ×1** | 기존 불길한 금고 3% **SUPERSEDED** |
| 고대의 심장 | **고대도시 상자 3% ×1 유지** + **왕릉 수호자 드롭 50% ×1 추가** | 기존 고대도시 3% 경로는 유지 |

- 신규 불·바다 보스 및 왕릉 수호자 전리품 연동은 **설계 확정 / 구현·스폰·재도전 검증 별도**.
- 구형 바다 신전 구조물 ID 오류는 구형 경로 관련 코드 이슈이며, 폐기된 획득 규칙을 되살릴 이유가 아니다.
- 위 코어 확률, 하늘섬 보상은 실제 loot table과 무관하게 문서상 최종 승인 수치다. 구현된 것처럼 표시 금지.

### 18.5 레시피 북 / 제작 / 장비 규칙 (Q17–Q21 + 기존 무한 내구도 결정)

- **Q17 A**: 3×3 \`shaped\` 제작법 좌우 반전 허용. 다른 회전/반전은 자동 추가하지 않음.
- **Q18 B + Q19 통합**: 바닐라 레시피 북/Advancement 해금 메커니즘 활용; 해당 장비의 **핵심 원소 코어를 최초 획득**할 때 관련 제작법 표시. 다른 원소 제작법을 일괄 해금하지 않음. 바람 활은 **돌풍 파편**이 핵심 재료. **직접 올바르게 배치하여 제작하는 것은 레시피 북 미해금 상태에서도 허용**. 이더리움 주괴·돌풍 파편 자체의 독립 해금 조건은 기존 바닐라 규칙과 충돌하지 않게 구현 검토할 사항이며 새 임의 관문을 도입하지 않음.
- **Q20 A**: 결과물은 신규 장비. 입력 기존 무기의 인챈트, 내구도 상태, 기존 강화 수치 등은 **계승하지 않음**.
- **Q21 A**: 제작에 사용하는 기반 무기의 잔여 내구도 제한 없음(부서지지 않은 실제 아이템이면 사용).
- **기존 승인 규칙 재확인**: T2 원소 장비는 **무한 내구도**, 따라서 내구도 소모와 수리 재료/수리 시스템 불필요. 대화에서 Q22로 제시했던 수리 방안 A/B/C 모두 **VOID — NOT A DECISION**. 기존 Enhancement 상한 **+20**과 마일스톤(+5/+10/+15/+20)은 별개로 **유지**. 무한 내구도와 강화/모루/인챈트 호환성은 실제 코드 검증 대상이지 설계 재협상 사유가 아니다.
