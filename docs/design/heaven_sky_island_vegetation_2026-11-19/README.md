## 9. 권장 시안 (확정 아님)

1. **V5 (환상적인 천국 정원)를 기준안으로 권장.**

   * 비용(28/35/45/7)은 V1과 거의 같다.
2. **V1을 보수적 대안으로.** 등나무 계열(블록 2)이 없고, 바닐라 친화성이 더 높다.
3. V2는 대형섬 전용 구성, V3의 꽃밭 밀도는 V5의 빈 구역 채움 규칙으로 차용을 검토한다.

## 10. 실제 구현 시 해결할 기술 문제

1. **거대 꽃 구현 방식 선택**(§3 A/B/C)과 파트 블록 설계: 모델 요소 범위 제한(블록당 최대 3×3×3), 파트 간 이음매, 회전 변형 수
2. **파괴·드롭 규칙:** 파트 하나를 부쉈을 때 전체가 무너질지, 남을지
3. **충돌 판정:** 꽃잎·잎의 VoxelShape, 꽃 위로 올라갈 수 있는지 (§6 엄격/관대 차이 91–99%)
4. **조명·AO:** 비고체 커스텀 모델은 면 컬링·AO 처리가 달라 그늘 표현이 렌더와 다르다. 그림자는 실제 게임에 없다(바닐라는 그림자 대신 광원 레벨 사용).
5. **월드젠 배치:** 식생을 섬 NBT에 굽거나(템플릿 19종 × 시안) 지형 위 피처로 분리하는 방식 중 선택. 구조물 템플릿 크기 한계와 jigsaw 연결점 회피.
6. **신규 잔디와 식물 생존 조건:** `heaven_grass_AL`이 `#minecraft:dirt` 계열 태그를 가져야 꽃·묘목이 자란다.
7. **색 고정:** 신규 풀·덩굴·잎은 바이옴 틴트 없이 고정색이어야 A 잔디와 맞는다(바닐라 short_grass 틴트 불일치 해결).
8. **성능:** 거대 꽃당 사변형 수(§3 노출면 추정), 섬당 거대 꽃 개수 상한
9. 신전·폐허 템플릿 적용 시 입구 마스크와 기존 구조물 블록 회피
10. 보류 요소(빛버섯·발광꽃)는 광원 블록·발광 텍스처가 필요하다. 이번 범위 밖이다.

## 11. 렌더러와 실제 게임의 차이

* 지형: 1·2차와 같은 직교 투영 ray-cast에 바닐라/컨셉 16×16 텍스처, MC식 면 밝기, 정점 AO를 쓴다.
* 식생: 1/4블록 복셀이다. 실제 커스텀 모델(1/16 정밀도, 텍스처 UV)보다 거칠고 텍스처 대신 단색 + 복셀별 명도 변화로 표현했다.
* 이번 라운드에서 **식생이 드리우는 방향성 그림자**를 추가했다. 지형끼리의 그림자는 없다. 실제 게임에는 이런 그림자가 없고, 대신 광원 레벨과 AO만 있다.
* 원근 투영, 밉맵, 안개, 시간대, 바람 흔들림, 파티클은 없다.
