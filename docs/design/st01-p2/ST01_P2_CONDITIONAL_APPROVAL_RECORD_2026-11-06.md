### D01 해석 (소유자 명확화)

- 지하 수평 확장량은 **공동뿐 아니라 벽체·기초·구조재까지 포함한 전체 생성 구조물**을 기준으로 측정한다.
- X/Z ±40을 넘는 것이 무조건 금지되는 것은 아니다. 다만 **필요성을 검증하고 최소 확장량을 산정**해야 한다(ST01-P2-D01(B) 조건 유지: 확정 공간 축소 금지, 위험 별도 기록, 무제한·신규 방 자유 추가 아님).
- 이 해석에 따라 P2 보고서의 "확장 0 / X1 PASS"는 **공동·예약 기준 결과**로 읽어야 한다. 전체 구조물(벽 포함) 기준으로는 아래 P2-F1이 열려 있다. P2 모델은 수정하지 않았다.

### P2-F2 최대 지하 깊이 — OPEN (확정하지 않음)

P2 잠정 24(L3 바닥 −22 + 슬래브 2). P3는 홀 바닥을 L3 바닥과 같게 두어 **추가 깊이 0**. 비밀 보물창고를 홀 바로 아래에 쌓으면 후보 39, 측방이면 24. 비밀 묘실 크기 미정이라 깊이 산정 불가. Q98 유지(새 상한·무제한 모두 만들지 않음).

### P2-F3 부속실(Q36) 개수·위치, 비밀 묘실 크기 — OPEN

### P2-F5 주 통로 계단식 천장(Q17/Q41) — UNVERIFIED

### P2-F7 D-3 동·서 방향 — OPEN (확정하지 않음)

P2 모델상 동·서는 정확한 거울이며 모든 지표가 같다. P3에서도 같은 결과(복셀 거울 일치)이며, 비기하적 차이는 손 방향(좌/우) 뿐이다. 결정에는 모델 밖 정보(지형, 이웃 구조물 방향, 소유자 선호)가 필요하다.

## 4. P3로 전달되는 조건

1. `HALL_RES`(예약 X −40..−2, Z 2..40, Y −24..−5)와 `HALL_INT`(청정 내부 X −37..−5, Z 5..37, Y −22..−7)는 **고정 입력**이다. 줄이지 않는다. 예약 안에 들어가지 않는 요소는 치수를 조용히 줄이지 말고 충돌로 보고한다.
2. 입구 포트 `T`(X −22..−20, Y −22..−20, Z −1..4; 홀 벽 포트 Z 2..4)는 고정. 홀 내부 첫 셀은 (−21, −22, 5).
3. 홀 외부 이웃(의식 전실 `A`, 비밀 구역 후보 `VAULT_A`/`STAIR_A`)과 벽 두께 2 이상, 지상(Y=0)까지 덮개 확보.
4. 홀 구조(벽·기초·슬래브 포함)는 ±40 안(P2-F1과 같은 기준). 홀은 이미 X=−40, Z=40에 닿으므로 어떤 홀 요소도 이 면을 넘지 않는다.
5. 동·서는 정확한 X 거울로 모두 검증하며 어느 쪽도 확정하지 않는다. 좌우 비대칭 요소(보조 상자 벽감 등)는 거울 시 손 방향이 바뀐다는 사실을 보고한다.
6. 비밀 구역은 예약·연결성만 다룬다(P4 상세).
7. 모든 새 수치는 PROPOSED로 표기한다.
