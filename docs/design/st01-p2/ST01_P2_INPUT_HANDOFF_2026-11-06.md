## 3. PROPOSED / 미승인 (P2 입력으로 쓸 때 반드시 표시)
- prep V1(명시적으로 "NOT YET OWNER-APPROVED"): 바닥 datum L1=−5, L2=−11, L3=−17; 방 목록 U00–U07·A/B/C/D 구역; 방 치수(예: U07 17×15); 서/동 배치 할당; 4개 일반 무덤·4개 부장품실·2개 부속실 개수. → 개수는 Q07/Q35/Q36에서 **미확정**으로 재확인됨.
- **충돌 가능성(승인 간):** prep V1의 U07 17×15는 Q43(33×33) 승인으로 대체됨(V1은 미승인이므로 Q43이 우선, 에스컬레이션 불필요).
- P1: 모든 치수(§1).
- 미결정(확정 설계 아님): 부속실 개수·위치, L2 방 개수, 비밀 하강 계단·지하실 좌표, 신규 최대 깊이, 보물고/지하실 접합 좌표, 광물 블록 채굴 가능 여부, 골렘 대체 접근 방식, 횃불 간격.

## 4. P2 착수 시 필요한 입력 목록
1. D-3 회전 방향 (또는 두 방향을 병행 검증하는 지시).
2. E1 이후 첫 구간: 7폭 주 통로 계속 길이, 휨(Q39), 천장 하강 방식(Q41), 발 층 −6에서 L1 바닥 맞춤 방식(두 번째 계단 추가 vs 직접 L1 −6; prep −5와 차이).
3. 푸트프린트(±40)를 지하 공동이 넘어도 되는지 — 근거 문서 없음, **소유자 확인 필요**.
4. Q37 "엇갈림" 중심 위치와 Q97 연장 방식.
5. 신규 최대 깊이 산정 기준 (3D 맞춤 후 결정; 임의 설정 금지).
6. 왕실 홀 33×33과 보물고 21×25가 점유하는 수평 영역이 가용 33블록 진행 폭·엇갈림과 양립하는지 (P2의 첫 검증 항목).

## 5. 재검증 조건
P1 변경이 있을 때는 승인 기록 §5 표에 따른다. 추가로 D-3 확정, Q37 중심 확정, 최대 깊이 확정 시 P1 인터페이스(E1)와 지하 배치를 재대조한다.

## 6. 착수 가능 여부
- **잠정 착수 가능** (E1 기준선 위, 두 방향 병행 검증 전제). D-3 확정 전에는 P2 산출물이 "방향 가변"으로 표시되어야 한다.
- 소유자 확인 필요 사항: D-3, 푸트프린트 초과 허용 여부.
- 아직 허용되지 않는 것: NBT/월드젠 구현, P1 PROPOSED 값의 최종 승인.
