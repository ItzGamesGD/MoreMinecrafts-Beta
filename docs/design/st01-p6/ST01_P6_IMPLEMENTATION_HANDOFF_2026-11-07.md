## 3. 구현 전에 먼저 필요한 결정

## 4. 구현 시 지켜야 할 경계 (이 설계의 전제)

- 보스 사망 처리, 상자 봉인, 영속 기록은 변경하지 않는다(권위·기존 구현 유지).
- 금 골렘은 분리 엔티티이며 안내 실패 시에도 비밀 창고 접근이 영구히 불가능해지지 않아야 한다.
- 새 필수 퍼즐·방을 추가하지 않는다(연결용 계단·참·통로와 Q15 묘실 외 없음).
- 본 모델의 PROPOSED 값(묘실, 장식 요소, 연결 통로 세부)은 승인 값으로 취급하지 않는다.

덮개 거동, 열린 구멍 낙하·피해, 보스 전투(BOSS-R1), 금 골렘 경로탐색, 월드젠·지형·청크, NBT 생성, 클라이언트 시각, 광원·유체·몹 누출.
