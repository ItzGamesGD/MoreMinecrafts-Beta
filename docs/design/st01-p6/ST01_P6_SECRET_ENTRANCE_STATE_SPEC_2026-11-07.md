# ST-01 P6 — 비밀 입구 상태 명세 (2026-11-07)

상태: **설계 명세 / 구현 승인 아님.** 근거: 사용자 결정(A안 바닥 블록 제거형), P3 조건부 승인 기록(비밀 입구 구역 X −9..−5 Z 33..37 Y −22..−19), P5·P6 복셀 검증. 모든 좌표는 동쪽 기준이며 서쪽은 정확한 X 거울(−x)이다.

## 1. 기하

| 항목 | 값 |
| --- | --- |
| 홀 바닥(발 높이) | Y −22 (바닥 블록 상단층 Y −23, 슬래브 Y −24..−23) |
| 제거 대상(12칸) | X −9..−6 × Z 33..35 × Y −23 (4×3) |
| 숨은 공동(닫힘에서도 존재) | 12칸 + 계단 공동 전체 (CLOSED에서 밀폐) |
| 숨은 계단 | 폭 3, 머리 공간 4, 발판 7개, 높이열 −22 → −30 (총 낙차 8 = 발판 7 + 첫 칸 1) |
| 관통 체적(P4 선언) | X −9..−5 × Y −24..−19 × Z 33..37 |

## 2. 상태

| 상태 | 정의 | 검증 | 판정 |
| --- | --- | --- | --- |
| **CLOSED** | 12칸이 고체. 홀 모든 칸(바닥 상단층 이상)이 P3 모델과 복셀 동일. 추락 구멍 0. 비밀 구역에 걸어서 도달 불가. 홀 공기에서의 6방향 flood-fill이 덮개층 이하 비밀 구역 칸에 도달 0 | P5.K1, P5.K2, CO4 | 정적 PASS |
| **OPEN** | 12칸이 공기. 홀 변화는 이 12칸뿐(해석 상자 교집합과 일치, 관통 체적 안). 진입광장→…→홀→숨은 계단→참→창고→거대 상자 앞 5칸 도보 연결. 계단 머리 공간 ≥4 | P5.K4, P5.K3, P5.S1, ST1, CO1 | 정적 PASS |
| **CLOSED→OPEN** | 정확히 12칸 제거, 다른 칸 변화 0 | CO2, CO3 | 기하 PASS / 트리거 BLOCKED |
| **OPEN→CLOSED** | 정확히 12칸 복원, 원상 복귀(복셀 일치), 인접 바닥 고리 14칸 변화 0 | CO2, CO3 | 기하 PASS / 복원 규칙 BLOCKED |

## 3. 측정된 위험 (수정하지 않음)

- **FIND-P6-1 낙차:** OPEN에서 구멍 열별 옆 낙차 — X=−9: 1, X=−8: 2(남·북 가장자리), X=−7: 3, X=−6: 4. X=−6 열은 4블록(첫 보이는 단 발 높이 −26)이라 바닐라 낙하 피해가 1 발생할 수 있다(3블록 초과부터). 완화(난간, 단 모양, 허용)는 설계 결정이며 만들지 않았다.
- **FIND-P6-2 복원 시 점유:** OPEN에서 절개 열 안에 서 있을 수 있는 위치가 12개. 복원 시 점유 처리(차단/지연/밀어내기)는 미정이며 기본값을 만들지 않았다.
- 덮개 아래 숨은 공동 12칸은 CLOSED에서 홀 바닥 아래 밀폐 공기 주머니로 남는다(무해한 기하 사실; 광원/몹 스폰 거동은 UNVERIFIED).

## 4. 덮개 구현 후보 비교 (결정 아님; A안은 사용자 결정)

| 후보 | 추가 공간 | 정적 평가 | 상태 |
| --- | --- | --- | --- |
| A 블록 제거형 | 0칸 | 슬래브 두께 변경 없음. 제거/복원 모두 12칸 변화 | 사용자 채택 |
| B 슬라이딩 패널 | ≥12칸 주머니 | 2칸 슬래브의 하층(Y −24)에 두면 홀 바닥 공기와의 분리 1(요구 2) → 슬래브 증축 또는 외부 주머니 필요(깊이 증가 가능) | 미채택 |
| C 피스톤/구조물 | ≥12칸 주머니 | B와 동일 + 장치 노출 | 미채택 |

## 5. 트리거·보스 연계 (미확정)

- 권위: 승리 후 금 골렘이 확장 Q16 창고로 안내, 안내 실패 시에도 접근이 영구히 불가능해지면 안 된다(비잠금 대체 접근, 정확한 방식은 OPEN).
- 열림 시점 후보(결정 아님, 구현 기본값 없음): 보스 처치 직후 / 골렘 도착 시 / 플레이어 상호작용. 이 중 어느 것도 선택하지 않았다.
- 비잠금 요구 때문에 "골렘 도착만이 유일한 개방 수단"인 설계는 권위와 충돌할 수 있다(대체 경로 필요). 어떤 대체 경로를 쓸지는 사용자 결정이다.
- 보스 전투 중에는 CLOSED가 유지되어야 전투 공간(P3 홀)이 P3 검증과 동일하다. 보스 코드는 블록을 설치/파괴하지 않으므로 전투 자체가 덮개를 바꾸지 않는다(코드 읽기로 확인; 실전 UNVERIFIED).
