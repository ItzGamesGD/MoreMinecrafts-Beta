- "후보 C 승인"은 P2 좌표를 바꾸는 승인이 아니라 *P6 통합 사양에서 채택*한다는 뜻으로 적용했다. P2 조건부 승인 기록과 P2 모델 파일에 이 좌표를 반영하는 일은 별도 작업이다.
