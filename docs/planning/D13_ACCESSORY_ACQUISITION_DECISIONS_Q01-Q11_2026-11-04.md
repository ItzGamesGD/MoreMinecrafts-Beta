## 3. 후보로만 남긴 보조 공급 경로

- 별의 서약: 향후 엔드 탐험 콘텐츠
- 영혼 사슬: 향후 영혼 모래 골짜기 관련 콘텐츠
- 생명의 고리·잿불 반지: 왕릉·보루 잔해 등은 이전 질문에서 보조 후보로 언급됐으나 개별 품목별 매칭은 아직 확정되지 않음
- 눈의 부적: 기존 구조물의 제한적 보조 공급은 검토 가능하지만 **Q11에서 주 획득처 유보를 유지**. 구체적 보조 획득처 미승인

**주의:** 후보는 승인된 지급 경로가 아니다. 모든 장신구에 보조 공급처를 반드시 같은 개수로 배정할 필요도 없다.

## 4. 기존 설계 및 후속 작업과의 경계

1. **ST-01/D09:** 왕실에 생명의 씨앗·시간의 고리 배정. 두 품목의 독립 지급/공통 풀 경쟁 여부 미정. 왕릉 수호자의 고대의 심장 **50%×1** 유지. 중력의 심장 추가 지급 방식 미정.
2. **하늘섬/D10:** 별의 서약은 공중 시련탑 최상층의 장신구 보상 후보로 배정됐으나 기존 깃털·돌풍 파편 확률, 보상 슬롯, 구조물별 배분은 변경하지 않음.
3. **ST-05/D12:** Q07은 특수 도전도 획득처로 활용할 수 있다는 원칙이지, 투기장에 추가 장신구를 도입한다는 승인이 아님.
4. **ST-03/D11:** 본거지 프리미엄 품목 허용목록의 기존 보류 조건 유지. 이번 결정으로 본거지 지급 품목을 확정하지 않음.
5. **신규 T1 7종:** Draft PR #224의 별도 계열. 이번 12종 T2 배정과 혼동하지 않음. T1의 획득·제작식은 미정.
6. **유물 촉매:** 기존 장신구 +5/+10에 사용. 생존 공급처·갱신·수량·소비량의 최종 확정은 후속 D13 질문으로 남김.
7. **드롭 확률·가중치·중복 처리·구조물별 추첨 횟수:** 이번 Q01-Q11에서 수치 미승인. 실제 공급량과 성장 밸런스는 후속 검토.

**중요: 제작 슬롯 계산**
- T1 장신구 ×1 = **1슬롯**
- 미스릴 주괴 ×2 = **2슬롯**, 각각 1개
- 이더리움 주괴 ×1 = **1슬롯**
- 청금석 ×5 = **5슬롯**, 각각 1개
- 합계 **9개 재료/9개 슬롯**. 한 슬롯에 청금석 5개를 쌓아두고 5개를 한 번에 소비하는 레시피가 **아니다**.
- 결과 유물 촉매 ×1. 강화된 T1도 소비 허용하며 강화 자원 환급 없음.
- 바닐라 shapeless 레시피의 9개 ingredient로 표현 가능한지, 커스텀 T1의 데이터 컴포넌트가 다른 경우 매칭 및 레시피북 자동완성이 어떻게 동작하는지는 **구현 검증**. '미강화 우선'은 바닐라 자동 보장으로 단정하지 않는다.

### 7.6 구현 전 경계와 미결정

1. **촉매 레시피:** 9슬롯 shapeless 매칭, 모든 T1 종류·강화 상태 허용, 레시피북 미강화 우선, 서버 권위 소비·재시작 동작 확인. 별도 UI는 만들지 않는다.
2. **ST-05:** 현재 금고·열쇠·플레이어별 지급/기여 자격을 실제 구현에서 제한적으로 확인하고, 촉매 **확률은 미승인**으로 유지. 불멸의 검투사는 기존 ST-05 보스이며 별도 개발 브랜치에 존재할 수 있어 문서 브랜치에 코드가 포함됐다고 가정하지 않는다.
3. **광물 밸런스:** 미스릴 ×2/이더리움 ×1/청금석 ×5/T1 ×1의 제작 비용 유지. 공급량 비교 전 수량을 임의 수정하지 않는다.
4. **획득처 미결정:** T2 장신구별 보조 획득처 개별 배정 및 눈의 부적 주 획득처 유보.
5. **보상 불변:** 왕릉 수호자 고대의 심장 50%×1 등 기존 확정 보상, ST-05 기존 보상 및 다른 구조물 보상은 임의 변경하지 않는다.
