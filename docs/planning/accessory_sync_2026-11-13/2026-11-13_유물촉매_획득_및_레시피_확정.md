## 2. 상세 확정 명세

### 2.1 유물 촉매 (`relic_catalyst`) 제작 공식
- **제작 방식**: 작업대 3×3 Shaped 조합 (독자 화폐·상점 판매 없음)
- **슬롯 배치 (1번 ~ 9번 슬롯 순서)**:
  1. **1번 슬롯 (좌상)**: 강화석 (`enhancement_stone`)
  2. **2번 슬롯 (중상)**: 미스릴 (`mythril`)
  3. **3번 슬롯 (우상)**: 강화석 (`enhancement_stone`)
  4. **4번 슬롯 (좌중)**: 청금석 (`minecraft:lapis_lazuli`)
  5. **5번 슬롯 (중앙)**: 이더리움 파편 (`etherium_shard`)
  6. **6번 슬롯 (우중)**: 청금석 (`minecraft:lapis_lazuli`)
  7. **7번 슬롯 (좌하)**: 강화석 (`enhancement_stone`)
  8. **8번 슬롯 (중하)**: 미스릴 (`mythril`)
  9. **9번 슬롯 (우하)**: 강화석 (`enhancement_stone`)

```text
[  강화석  ] [  미스릴  ] [  강화석  ]
[  청금석  ] [이더리움파편] [  청금석  ]
[  강화석  ] [  미스릴  ] [  강화석  ]
```

### 2.2 획득 파이프라인 및 생태 연계
- **이더리움 파편 (`etherium_shard`)**: 오버월드 심층/지하(Y -32~64, 피크 16, 다이아 광석 생성량의 1/4)에서 `etherium_ore` 채광 → 원광 드롭(`etherium`) → 화로/용광로 제련을 통해 확보.
- **미스릴 (`mythril`)**: 오버월드 심부(Y -64~0, 피크 -48)에서 `mythril_ore` 채광 시 완성 재료 직접 드롭.
- **강화석 (`enhancement_stone`)**: 레드스톤 4 + 다이아몬드 4 + 청금석 1 조합(16개 산출).
- **청금석 (`lapis_lazuli`)**: 바닐라 채광 및 탐험 자원.

### 2.3 원본 문서 반영 지침 (에이전트 동기화용)
1. **§6.2**의 +5, +10 유물 촉매 수량 `1 잠정` 라벨을 `1 확정`으로 변경하고, 하단의 `유물 촉매(relic_catalyst)의 획득·레시피·아트는 미정이다` 문구를 확정된 3×3 레시피 명세로 교체한다.
2. **§12.1**의 광물별 소비처 목록에서 미스릴과 이더리움(파편) 항목에 유물 촉매를 추가한다.
3. **§16.1 U-05** 항목의 상태를 `미정 / 잠정`에서 `레시피·획득·수량 확정 (아트만 미정)`으로 갱신한다.
