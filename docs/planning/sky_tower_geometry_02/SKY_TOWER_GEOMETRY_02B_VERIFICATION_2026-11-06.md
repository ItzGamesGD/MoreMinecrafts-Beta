## 중앙 문양·제단 — 범위 분리 조건부 CONFLICT / 실제 도안 UNVERIFIED

중앙 문양 D17은 기존 규칙 `x²+z² < 8.5²`의 **채워진 예약 범위**로 검사한다.
실제 9×9 팔각형·삼중원·방사선의 선 좌표는 정의되지 않았다. 7×7 역시 목표 범위이며 꽉 찬 사각 문양으로 확정하지 않는다.
검사한 두 마스크는 ① 49열 전체 범위, ② 중앙 3×3을 뺀 40열 사각 환형 민감도 비교다.
②를 실제 환형 도안으로 승인하지 않는다. Q70 경계띠 폭도 미정이므로 D19−D17은 **폭 1 민감도**로만 저장한다.

| 바닥 탐색 영역 | 7×7을 수용하는 중심 수 | 중앙 D17과 분리되는 전체 범위 / 비교 환형 | 최소 중첩 전체 / 비교 환형 |
|---|---|---|---|
| 승인 내부 D25 | 225 | 0 / 0 | 19 / 16열 |
| 개별 유효 벽감 절삭 열을 합친 낙관적 영역 | 233 | 0 / 0 | 5 / 5열 |

낙관적 영역은 동시 절삭·바닥 확장이 승인되거나 검증되었다는 뜻이 아니다. 검사가 정의한 축 정렬 벽감에 대한 민감도 결과다.
7×7 전체가 바닥 영역 안에 있는 모든 정수 중심을 검사했으며, 배치별 실제 중첩 좌표를 `patterns.json`에 전부 저장했다.
최소 중첩 내부 배치의 한 예는 중심 `(-9,0)`이다. D17과 겹치는 19열은 다음과 같다.

```text
x=-8: z=-2..2  (5열)
x=-7: z=-3..3  (7열)
x=-6: z=-3..3  (7열)
```

이 배치의 3×3 제단도 `(-8,-1),(-8,0),(-8,1)`에서 중앙 예약 범위와 겹친다.
다만 3×3 제단만 검사하면 D25 안에서 D17과 분리 가능한 중심이 **96곳** 있다. 예: `(10,0)`에서 x9..11,z-1..1.
따라서 제단 자체가 무조건 불가능하다고 결론 내릴 수 없다. 제단의 실제 y는 각 후보 보행 바닥에 맞춰야 한다.
Q54의 제단 상면 +1, Q56 전면 계단 및 Q62 중앙 무단차를 만족하는 최종 3D 배치는 미검증이다.

**CONFLICT가 증명된 조건:** D25 내부에서 7×7 전체 범위와 채워진 중앙 D17을 서로 겹치지 않게 요구하면 불가능하다.
**UNVERIFIED:** 실제 선 도안끼리의 간섭, 중첩 허용/불허, 8개 주기둥·제단 수량·전면 계단·벽감·관문을 포함한 전체 배치.
문양을 축소·삭제·허용 중첩으로 바꾸지 않았고, 승인 조건 전체의 불가능성도 주장하지 않는다.
