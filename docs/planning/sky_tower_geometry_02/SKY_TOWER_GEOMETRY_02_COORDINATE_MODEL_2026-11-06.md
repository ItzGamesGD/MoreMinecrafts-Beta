## 2. 좌표계 정의

| 항목 | 정의 |
|---|---|
| 블록 좌표 | 정수 `(x, y, z)` = 단위 입방체 `[x,x+1)×[y,y+1)×[z,z+1)` |
| y0 | `y = 0` = 석조 기단의 **최하단 블록층** (Q27 "석조 기단 바닥"). 자연섬은 `y < 0` (Q27 제외) |
| 최상단 | `y = 79` = 최상층 아치 꼭대기 블록 (Q27). `y ≥ 80` 점유 금지 |
| 중심축 B형 (블록 중심) | 축이 열 `(0,0)`의 중심점 `(0.5, 0.5)`을 통과. 열의 반경 거리 `d = hypot(x, z)` |
| 중심축 C형 (블록 모서리) | 축이 열 `(-1..0)²`의 공유 모서리 `(0, 0)`을 통과. `d = hypot(x+0.5, z+0.5)` |
| 직경 D 원판 | `{열 : d < D/2}`. B형은 D 홀수, C형은 D 짝수일 때 X/Z 점유 폭이 정확히 D |
| (cx, cz) | B형: 열 `(0,0)` / C형: 모서리 `(0,0)`. NBT 템플릿 변환 시 `(x+22, y, z+22)` → B형 45×80×45, C형 44×80×44 |
| 기준축 | `+Z`(남) = Q61 주출입구 축 **표기 관례**. 모델이 D4 대칭이라 블록 결과에 영향 없음 |
| 외벽 기준 | 외벽 = `원판(D_wall) − 원판(D_inner)`, 두께 t = (D_wall − D_inner)/2 (축 방향 블록 수) |
| 내부/외벽 경계 | 원판(D_inner) 경계 = 내벽면. 그 밖 `원판(45) − 원판(D_wall)` = **예약 외곽대(RESERVE)**: GEOMETRY-03 요소(계단·기둥·난간·처마·차양) 전용, 이번 모델은 점유하지 않음 |

**중심 방식 선택 근거(파생, 신규 결정 아님):** Q65 9×9, Q67 지름 17, Q55 3×3, Q59 7×7 등 중앙·대칭 요소가 모두 홀수 크기이므로 정중심 대칭에는 B형이 필요하다. B형에서는 내부 직경이 홀수(25 또는 27)만 정확한 대칭이 된다. "약 26"을 정확히 26으로 두려면 C형(외경 상한 44)이 필요하다. 세 방식 모두 계산했다 — 선택은 §10 D2 결정 사항.
