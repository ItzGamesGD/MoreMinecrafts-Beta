# GEOMETRY-03C-P1 — 원형 경계 감사

기준 `bf873bdd818070473e25292d2f6c33de521fcf69`, B25-T3. 기존 03B C1 CSV의 Git blob을 고정해 검사한다. 새 구조는 생성하지 않았다.

축은 `(0.5,0.5)`, 블록 열 `(x,z)`의 중심은 `(x+0.5,z+0.5)`다. 기존 02B 원판은 `x²+z² < (D/2)²`이다. 두 독립 계산인 정수 제곱식 `4(x²+z²)<D²`와 실제 좌표 원판 집합 차집합이 일치한다. 따라서 259열은 이 규약에서 **실제 좌표 이탈**이며, X/Z 폭 45와 원형 반경 22.5는 서로 다른 검사다.

|---|---:|---|
| 일반 부재 전체 | 259 | 중복 제거 합집합 |

같은 열의 부재는 각각 집계하므로 부재별 합은 259가 아니다. `outside_D45.csv`는 `(x,z,부재)`별 y 집합, 중심 거리, 초과량과 모서리 거리를 기록한다. 전체 좌표·중복과 판정은 `results.json`에 있다.

전체 단위 블록의 가장 먼 모서리까지 포함하는 비교식은 `(2|x|+1)²+(2|z|+1)² ≤ D²`다. 이 대안에서는 일반 부재 361열이 D45 밖이다. 이 값은 02B 중심 기준을 바꾸거나 새로운 설계 조건으로 확정하지 않는다. 경계에 정확히 닿는 전체 블록은 비교식에서 포함한다.

발코니로 분류된 바닥·난간·받침만 D51을 적용하면 중심 기준과 전체 블록 비교 기준 모두 이탈 0열이다. 연결 아치·일반 기둥·차양·일반 난간은 발코니와 접촉하더라도 D45로 검사했다. 발코니 바깥쪽의 D45 이탈 자체를 D51 위반으로 취급하지 않는다.

P2 생성 제약: 일반 부재 후보 열마다 `center_inside(x,z,45)`를 적용하고, 발코니 전용 부재에만 `center_inside(x,z,51)`을 적용한다. 후보의 허용 영역은 기존 벽/내부 점유와 별도 검사한다. 전체 블록 기준도 병렬로 기록하되 사용자 결정 전까지 승인된 기본 기준을 대체하지 않는다. 발코니의 실제 국소성, 구조 접합, 아치·보행 충돌과 층별 간격은 이 경계 검사만으로 PASS가 아니다.
