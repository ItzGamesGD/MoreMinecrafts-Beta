## 2. 탐색 변수 · 후보 생성 방식 (산출물 1)

생성기 `p2_search.py`: OR-tools CP-SAT(**9.15.6755**, `data/search_env.json`)로 평면을 **공동** 탐색한다. 계단·기둥·난간·발코니를 순차로 고정하지 않고 하나의 모델에서 동시에 푼다. 모든 변수는 생성 시점에 원형 제약을 받는다.

- **계단 경로**: 패드 기준점 집합(4×4 패드 ⊂ D45 − D31)에서 단순 폐곡선(`AddCircuit`), +x 절단선 홀수 교차(벽을 정확히 1회 감김), 포털 앵커 `(17,0)` 통과. 시작 위상과 평탄 참·곡선 모두 솔버 선택(03B의 4×4 코너 패드 8각 경로군에 한정하지 않음).
- **걷는 면 W**: `pads`(03B와 동일: 모든 스테이션 패드 합집합) 또는 `lean`(4칸 단면 + 방향 전환 4×4 패드만).
- **상승**: 03B 규칙(같은 방향 11스테이션 연속 = 상승 가능 스테이션) 상승 가능 스테이션 ≥ 17(최대 층간 상승 17, 스테이션당 1블록). 입구 ±4는 보호(맨해튼 ≤4로 보수 근사).
- **난간**: 03B 규칙(걷는 면의 비벽 4-이웃 열마다 난간)을 그대로 모델링 → W의 모든 열은 4-이웃이 D45 안이어야 한다(Q26 “난간 포함 45”). 난간을 모델에 넣기 전 첫 시도에서는 난간 26열이 D45를 벗어났고, 그 시도의 3D 감사가 이 누락을 찾아냈다.
- **기둥**: 3×3, ⊂ D45 − D31, W·서로와 비중첩, W에 접촉, 걷는 면 바깥(축→기둥 선분이 W를 가로지름). 해제 변형(`no_ray`, `no_adj`)도 풀었다.
- **발코니**: 유효 7×3(가로·세로) + 난간 고리 ⊂ D51, 벽·W 비중첩, 접촉 열 ≥ k, 착지 평탄(접촉 스테이션 ±1은 상승 불가), 각도 45° 구간당 1개(Q81 해석, 별도로 해제 변형).
- **층·바닥판 귀속**: 평면은 C1/C2 공통, 3D는 C2 = C1을 y−1(03B와 동일, 기준 바닥판 모델은 02B baseline). C1/C2 차이는 결과 동일.

**가정(증명의 범위)**: A1 폭 4 = 03B 인증서(스테이션 4열 단면 + 방향 전환 평탄 4×4 패드). A2 상승은 03B 적격 규칙. A3 난간 = 03B 규칙의 일반 부재(D45 내). A4 발코니 접합 = 접촉 스테이션 ±1 평탄. A5 기둥 평면 위치는 4개 층에서 동일(층별 높이만 다름)이고 아치 시작 높이 +3은 03B 후보 값(임시).
