## 대안 모델 정의 (P3-A, P3-C)

생성기 `p3_generate.py`, 탐색 `p3_search.py`(OR-tools CP-SAT 9.15.6755, worker 1개, seed 1로 결정적).
- **ANN 걷는 면**: 중심 반경 15.5 ≤ r < 19.5인 열(B25-T3 벽 원판 바로 바깥, 반경 폭 4). 디딤판 높이는 각도의 함수이고, 같은 반경 단면에서는 높이가 같다. 포털 착지 ±12°, 층 시작·끝 높이 = F1–F4·성소 바닥.
- **상승 방식**: `slab`(반블록 단계, 아래 반블록/통 블록) 또는 `stair`(통 블록 + 상승 방향 stair 블록, 03B식).
- **난간**: 디딤판의 비벽·비띠 4-이웃 열에 2단. 같은 복셀에 기둥이나 그 층 발코니가 있으면 생략.
- **기둥(3×3)**: 띠 바깥 고리(D45 − D31 − 띠) 안에 있고 띠에 접촉. CP 조건은 “각도 G° 창마다 기둥 중심 ≥1”. 최소 G를 이분 탐색했다.
- **발코니**: 7×3 + 난간 고리 ⊂ D51, 띠·벽과 비중첩, 띠와의 접촉 ≥3열(개구부), 45° 구간당 1개, 층 = 구간 번호 mod 4(층간 2개, 회전 배치).
- **아치**: 03B와 같은 2×2 바닥 경로와 반원(Q87)을 쓴다. 반지름은 기둥면 사이 순 개구부(중심 거리 − 3)의 절반으로 잡았다. 03B는 경로 칸 수로 반지름을 잡아 대각선에서 반지름이 커지고, K2 초기판에서 다음 층 난간과 8복셀 충돌했다.
- **C1/C2**: C2는 y−1. 모든 후보에서 C1과 C2 결과가 같다.

- **U4**: 발코니 개구부 3열·평탄 착지 3칸이 Q73 “주요 평탄 구간”과 자연스러운 접근을 만족하는지.
- **U5**: 기둥이 층별 구간(디딤판−2 ~ 주두)으로 끊겨 있다(P2와 동일). 수직 연속 여부는 미정.
- **U6**: 경계 해석. 전체 블록 D45(T1)를 쓰면 ANN에 3×3 기둥 후보가 **0개**다. 상자 45와 D46/D47은 창 11°까지 가능하지만 감도 분석일 뿐 D45 충족이 아니다.
