- 원형 경계는 P5 중심 기준 D45/D51. 전체 블록 모서리 기준은 별도 미결정.
- 폭 반례는 반경 방향 선과 full-block 정사각형 경계. 지지·높이·연속 곡선 경로는 별도 검사해야 한다. 3.265를 전역 최소로 간주하지 않는다.

- G1은 형상 가능성을 확인하기 위한 임시 복셀 실험이며 승인된 난간 디자인이 아니다. 전체 폭4 검사 없이 통합 PASS 금지.
