# DECISION_REQUIRED

현 상태에서 INTEGRATION COMPLETE를 선언할 수 없다. 다음은 사용자 승인 없이 적용하지 않았다.

1. **자연 생성 정책/구형 탑 대체**: 현재 일반 하늘섬 spacing24/separation8/frequency.5, 고산14/5/.5. 바이옴 태그/오버월드 방향은 기존 권위에 있으나 승인 탑을 이 구형 탑 섬에 대체할지, 별도 자연 생성으로 할지 미정. 기존 수치를 승인된 신규 탑 수치로 간주하지 않는다. 선택: 기존 탑 섬과 정책 재사용(섬 접속·회전·청크 시험 필요), 또는 전용 정책 확정까지 수동 배치만. 사용자 응답 대기.
2. **기능 금고 설정**: 승인 NBT 금고8개는 vanilla reward. 현재 권위의 하늘섬 금고는 `moreminecrafts:chests/sky_islands/vault`(깃털15%·돌풍 파편5%). 좌표·외관을 유지한 기능 NBT loot table 변경도 승인 전 보류. 별도 Java 추가 지급으로 우회하지 않는다.
3. **물리 결계 추가**: NBT 원본은 유지하되 런타임에 공기72칸을 barrier로 채우고 해당층 완료 시 제거하는 최소안을 제안. 로컬 x39..44,z27, y11..13/22..24/34..36/48..50. 전부 실제 NBT에서 공기임을 검증. 이 제안은 아직 미적용이며 가상 충돌 결계는 별도 엔티티/네트워크 설계가 필요하다. 어느 쪽도 기존 블록 보호·텔레포트 복귀를 추가하지 않는다.
4. **파괴된 필수 스포너**: Q22는 블록 파괴 우회를 허용한다. 스포너를 파괴했을 때 강제 완료/재생성/제한을 임의로 만들지 않았다. 현재는 완료 증거가 없어 해당 비트가 잠긴 채 유지된다. 회복 정책 필요.
5. **옥상 특별 보상/전체 완료**: 권위는 특별 보상을 요구하지만 승인 NBT 옥상에는 특별 금고가 없다. 위치·블록·세부 테이블 미정. 중앙 유물에 능력·보상을 추가하지 않는다. 성소 도달과 4층 전투 완료를 같은 이벤트로 확정하지 않았다.

이미 확정된 것: 층당 모든4스포너 완료, 바닐라 시련 보존, 구조물 단위 영구·공유 해제, 일반 이동만 막고 우회 허용. 이 규칙은 재승인 대상이 아니다.
