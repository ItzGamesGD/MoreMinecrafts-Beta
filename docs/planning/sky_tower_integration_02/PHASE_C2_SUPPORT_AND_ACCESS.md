# Phase C-2 지지와 접근

B형 대표 표본의 연결대는 탑 외곽 x49의 하부 slab과 맞춘 실험용 stone-brick 하부 slab x50..53, 3 또는 5칸 폭, 양측 stone-brick-wall 난간이다. 3칸 폭은 바닥 12개와 난간 8개다. 이는 플레이 가능 폭의 승인 기준이 아니다. 상대 좌표는 탑 모델의 좌표이고 최종 좌표는 JSON을 따른다. 높이 차이를 보완하는 계단은 아직 설계하지 않았다.

기단 직하 863열 각각의 기존 섬 블록 및 위치를 후보 JSON에 기록했다. 알려진 솔리드 여부는 제한된 ID 목록의 보수적 분류로 물리 충돌 상자·기초 강도·기존 건축물 손상을 증명하지 않는다. 공중 노출 및 3D 형상은 JSON과 좌표도에 표시했다. 네 지지점의 수직 기둥 탐사 및 두 개의 단순 수평 받침을 모델링했다. 받침은 탑 아래 빈 공간을 지나 부모 템플릿의 알려진 솔리드와 닿는 지점까지만 설치하며, representative 표본은 15–20블록이다. 각각의 좌표·앵커·길이는 JSON의 `bracket_probes`와 `bridge_and_support_voxels`를 본다. 구조물 전체의 충분한 지지나 시각적 일체감은 **UNVERIFIED**다. 본체 NBT는 건드리지 않았다.

독립 재생은 3칸 폭 대표 표본의 다리 끝 다음 (39,16,21)이 meadow에서 grass block이고 나머지 다섯 섬에서는 air임을 확인했다. 이 점은 곧 보행 실패나 경로 부재의 증명이 아니며 인접 경사·상하 단차와 기존 경로를 별도로 탐색해야 함을 뜻한다. 입구 위 중심 열에 meadow tall_grass (34,18,21), forest oak_leaves (34,19,21)가 검출된다. 전자는 비공기라는 사실만으로 충돌한다고 단정하지 않는다. 실제 Minecraft 블록 형태, 플레이어 높이·이동 판정을 확인해야 한다.

4방향 상대 변환은 좌표 수식과 역변환만 검사했다. 부모 전체 회전, 슬랩·난간 상태의 실제 회전, 벽 연결, 구성요소 간 인게임 충돌, 주위 섬 자식과 주요 경로, 실제 첫 전투층까지의 도달은 **UNVERIFIED**다. 실제 생성 시 덮어쓰기는 확정되지 않아 섬→탑→부속물 모델을 결과와 명시적으로 분리한다.
