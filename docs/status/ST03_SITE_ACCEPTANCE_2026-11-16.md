## 3. 후보 배치 및 `St03Eligibility.evaluate` 통과율·탈락 사유

### 후보 산출 방식

- `moreminecrafts:st03_pillager_headquarters` (`Registries.STRUCTURE_SET`)에서 읽어 온 실제 설정:
  - `spacing = 48` 청크(`768`블록), `separation = 16` 청크, `salt = 91403`, `spread_type = triangular`
- `RandomSpreadStructurePlacement.getPotentialStructureChunk(seed, rx * 48, rz * 48)`를 직접 호출 (`findNearestMapStructure` 미사용).
- 각 시드 `rx, rz ∈ [-25, +25]` (`51 × 51 = 2,601`개/시드, 10시드 합계 `26,010`개; 시드당 커버 범위 `±19,200`블록 = `38,400 × 38,400`블록).
- `St03Eligibility.evaluate(terrain, originX, originZ)`는 다음 **단락(short-circuit) 순서**로 판정합니다:
  1. `fullFootprintEligibleBiome` (`REJECT_BIOME` — 중심 + `112×112` 전체 8블록 격자 바이옴 모두 적격)
  2. `surf > floor + 1` (`REJECT_WATER` — `112×112` 내 4블록 격자 어느 한 점이라도 물 깊이 2블록 이상)
  3. `diff > 5` (`REJECT_HEIGHT_DIFFERENCE` — `MAX_HEIGHT_DIFFERENCE = 5`)
  4. `cut > 3` (`REJECT_CUT` — `MAX_CUT = 3`)
  5. `skirt > 5` (`REJECT_SKIRT` — `MAX_SKIRT = 5`)
  6. 중심 셀 `@ foundationY` (`REJECT_BIOME`)
  - **동굴/빈 공간(`CAVE_VOID`) 및 마을·구조물 겹침(`VILLAGE_STRUCTURE_OVERLAP`):** 현행 `St03Eligibility.evaluate`에는 구현되어 있지 않으므로 모든 후보에서 탈락 건수 `0`으로 기록했습니다(미구현).
