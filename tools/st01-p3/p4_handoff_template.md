## 3. P4가 정해야 할 열린 항목

1. 숨은 입구 메커니즘과 위치 확정(구역 안 또는 다른 후보). 구역 폭이 5라서 계단 폭 ≤ 5가 되며, 폭을 넓히려면 열주 받침(X ≤ −10)과 충돌하므로 위치 변경이 필요합니다.
2. Q14 방향 전환 + 참을 포함한 숨은 계단. P2 후보 A는 홀 바닥(−22)에서 보물창고 내부 바닥 −37까지 15블록 하강(`STAIR_A` 평면 11×31)입니다 — *적합성은 미검증*.
3. 비밀 묘실(Q15)의 크기·위치(미정) → 최대 깊이(Q98) 산정 불가 상태 유지.
4. Q63 확장 보물창고와 Q16 기존 발자국의 관계, 4개 바닥 기초 기둥(높이 7)과 계단식 천장 8/9/10의 국소 간섭.
5. 황금 골렘 안내 경로와 비잠금 대체 접근 경로.
6. 광물 블록 채굴 가능 여부(미결), 거대 상자 높이(미결), 상자 용량·영속성(엔지니어링 검증 필요).
