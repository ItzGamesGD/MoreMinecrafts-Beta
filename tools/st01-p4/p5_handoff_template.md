# ST-01 P5 통합 검증 인계 문서 (2026-11-07)

**상태: PROPOSED 인계. 설계 권위가 아니며 P5 설계·검증을 대신하지 않습니다.** P1–P4 산출물을 통합 검증하기 위해 무엇이 준비되었고 무엇이 막혀 있는지만 기록합니다.

| 단계 | 산출물 | 상태 |

## 2. P5 착수 가능 여부

**착수 가능(모델 수준 통합).** 모든 단계가 같은 좌표계·같은 복셀 격자(`p2_core`, X/Z −64..64, Y −60..40)를 쓰며 P4 검증기는 이미 P2+P3+P4를 한 월드로 합쳐 검사합니다. 다만 아래 §3 결정이 없으면 P5는 후보 A/B와 동·서의 **모든 조합**(4개)을 병행해야 하고 최대 깊이를 확정할 수 없습니다.

## 4. P5 통합 검증 항목 제안 (착수 시 범위에서 확정)

1. 전 구조 통합 복셀: 지상(P1) + L1–L3(P2) + 홀(P3) + 비밀 구역(P4)의 충돌·접촉·최소 벽 두께를 한 번에.
2. 통합 동선: P1 입구 → 홀 → (보스 승리 후) 비밀 입구 → 보물창고. 현재 보행 거리(P4 검증기 측정): 홀 석관단 → 입구 구역 19걸음, 입구 구역 → 상자 정면 A {{HS_A}} / B {{HS_B}}걸음, P1 착지 → 상자 정면 A {{PA}} / B {{PB}}걸음.
3. 전체 ±40 초과량(벽체 포함)과 청크·지형 위험(UNVERIFIED).
4. 최대 깊이 확정(후보 선택 후): 현재 계산값 A 39 / B 32.
5. 열린 단면 상태/닫힘 상태의 병행 검증(P3=닫힘, P4=열림).
6. 황금 골렘 안내·비잠금 대체 경로(경로 설계는 P4 이후 미착수).
7. 재현: `python3 -I tools/st01-p1/st01_p1_model.py <out>`, `python3 -I tools/st01-p2/st01_p2_verify.py <out>`, `python3 -I tools/st01-p3/st01_p3_verify.py <out>`, `python3 -I tools/st01-p4/st01_p4_verify.py <out>`; 음성 대조 `tools/st01-p3/st01_p3_mutation_tests.py`, `tools/st01-p4/st01_p4_mutation_tests.py`.

## 5. 입력 고정 목록 (바꾸면 재검증)

- P3: 홀 예약·내부·기둥·석관단·비밀 입구 구역(X −9..−5, Z 33..37).
- P4 후보 공통: 계단 폭 3·머리 높이 4·참 5×5·통로 5폭 6높이(PROPOSED), 보물창고 구조(§3.2), 비밀 묘실 대표 후보.
- 모든 PROPOSED 값은 승인 전까지 설계 권위가 아닙니다.
