### 1.2 `N=0..2` (`5×5=25` 청크 오프셋) 탐색 위치별 결과

- `N≤2` 탐색은 Chebyshev 반경 `r = max(|dx|, |dz|) = 0, 1, 2` 순으로 나선형 탐색하며 첫 전수 통과 위치에서 채택한다.

  - 표본(225개) 통과 위치: **`20,836`개 (`3.204%`)**
  - 전수(12,544열) 통과 위치: **`10,422`개 (`1.603%`)**
- 전수 통과한 **`1,912`개 후보**가 채택된 탐색 반경(`r`) 분포:
  - **`r = 0` (`N=0` 정중앙, 1개 위치):** `400`개 (`20.92%`)
  - **`r = 1` (`N=1` 주변 8개 청크):** `650`개 (`34.00%`, 누적 `1,050`개 = `54.92%`)

   - **방향 C (물 표본 상한 또는 토공 한계 조정):** 강 인접 탈락을 완화하기 위해 물 표본 상한(`5% -> 10%/15%`)을 조정할지, 혹은 사문화된 `MAX_HEIGHT_DIFFERENCE (P <= 20)`와 `MAX_CUT (10)` / `MAX_SKIRT (12)` / `MAX_FOOTING_FILL (16)`의 결합 관계를 재설계할지 여부.
   - **방향 D (탐색 반경 `N` 조정):** 지형 규칙을 그대로 두고 탐색 반경을 `N=3`(`+52.1%`) 또는 `N=4`(`+108.5%`)로 넓힐지 여부.
